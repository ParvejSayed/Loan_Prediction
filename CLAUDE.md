## Project Overview

Loan Approval Prediction system that uses a Gradient Boosting model to predict whether a bank loan application will be approved. The original Flask app (`app.py`) has been replaced with a FastAPI backend.

## Setup

```bash
conda create --name env python=3.11
conda activate env
pip install -r requirements.txt
```

## Running the Application

The system has two components that must run concurrently:

```bash
# Terminal 1 — FastAPI backend (port 8000)
uvicorn main:app --reload
# or: python main.py

# Terminal 2 — Streamlit frontend (port 8501)
streamlit run streamlit_app.py
```

The Streamlit UI (`streamlit_app.py`) hardcodes `API_URL = "http://localhost:8000"` and POSTs to `/predict`.

API docs are available at `http://localhost:8000/docs` (Swagger UI).

## Training / Generating Artifacts

Run the Jupyter notebook to retrain and regenerate pickle artifacts:

```bash
jupyter notebook "Loan_prediction_on_actual_dataset (1).ipynb"
```

The prediction pipeline expects these files under `artifacts/` (not tracked in git):
- `final_preprocessor.pkl` — sklearn `ColumnTransformer` pipeline (required)
- `gradient_boosting_best_model.pkl` — trained GradientBoostingClassifier (required)
- `kmeans_model.pkl` — KMeans cluster model (optional)
- `cluster_risk_map.pkl` — dict mapping cluster ID → risk probability (optional)

If the KMeans artifacts are absent, `predictionPipeline._add_cluster_features()` skips the cluster feature step silently.

## Architecture

```
main.py                          ← FastAPI app, /predict endpoint, Pydantic validation
streamlit_app.py                 ← Streamlit UI, calls FastAPI via HTTP
src/
  pipeline/prediction_pipeline.py ← predictionPipeline + customClass
  logger.py                      ← file-based logging → logs/<timestamp>.log
  exception.py                   ← CustomException with file/line detail
artifacts/                       ← pickle files (generated by notebook, not in git)
```

### Prediction Flow

1. `POST /predict` receives a `LoanApplication` Pydantic model (11 fields, strictly typed with `Literal` enums).
2. `customClass(**data).get_data_frame()` converts it to a single-row `pd.DataFrame`.
3. `predictionPipeline.predict(df)`:
   - Optionally prepends a `risk_probability` column via KMeans cluster assignment.
   - Loads and applies `final_preprocessor.pkl` (handles numeric scaling, KNN imputation for Credit_History, ordinal encoding, one-hot encoding).
   - Loads and runs `gradient_boosting_best_model.pkl`.
4. Returns `{"prediction": 0|1, "status": "Approved|Rejected", "message": "..."}`.

### Preprocessing Details (important when adding features)

| Column | Treatment |
|---|---|
| ApplicantIncome, CoapplicantIncome, LoanAmount, Loan_Amount_Term | Mean impute → MinMaxScaler |
| Credit_History | KNN imputer → MinMaxScaler |
| Dependents, Property_Area, Education | Most-frequent impute → OrdinalEncoder |
| Gender, Married, Self_Employed | Most-frequent impute → OneHotEncoder (drop first) |

Best model hyperparameters: `learning_rate=0.2`, `max_depth=4`, `n_estimators=100`.

## Key Notes

- The README still references the old Flask app (`python app.py`, port 5000) — this is outdated; the current backend is FastAPI on port 8000.
- `Loan_ID` column from the raw CSV is dropped during training and is not an input to the prediction API.
- Logs are written per-session to `logs/<timestamp>.log` relative to the project root.
